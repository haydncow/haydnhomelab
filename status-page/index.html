Security

    

      
No open ports on my router
This site reaches you through a Cloudflare Tunnel. The Pi connects out to Cloudflare, so nothing on my home network is open to the internet.

      
SSH keys only
Password logins are turned off. You can only log in with my key, and I tested that passwords get rejected.

      
Firewall blocks by default
UFW drops everything coming in, apart from the few things I've allowed from my home network and over Tailscale.

      
Private remote access
I manage the Pi from anywhere with Tailscale, an encrypted private network with 2FA on the account.

      
Automatic security updates
unattended-upgrades installs security fixes every day without me having to remember.

      
Only safe info on this page
No IP addresses, hostnames or software versions are shown here, because those help attackers.
